# MathGame 🧮

A console-based math quiz game built in C++ that tests your arithmetic skills.

## Features
- Choose number of questions (1-10)
- 4 difficulty levels: Easy, Medium, Hard, Mix
- 5 operation types: Addition, Subtraction, Multiplication, Division, Mix
- Color feedback — green for correct, red for wrong
- Final results summary with pass/fail

## How to Play
1. Run the program
2. Choose how many questions you want
3. Choose difficulty level
4. Choose operation type
5. Answer each question
6. See your final results

## Built With
- C++
- Visual Studio
